JARVIS Dashboard - Argo Workflows Design Attribution

This dashboard adapts operational user-interface concepts after surveying Argo Workflows.

Upstream repository: https://github.com/argoproj/argo-workflows

Adapted concepts:
- fixed routed shell
- list/detail
- graph/timeline/log composition
- explicit states
- list+watch invalidation/refetch

No Argo Workflows source code was copied. Kubernetes mutation semantics, including Kubernetes object, YAML, pod, and resource operations, were explicitly rejected and were not adapted. JARVIS retains its own authority model and data contracts.
